# まこマッチ 完成版スターター

## 起動
Node.js 20以上で `npm install` → `npm start`。
`.env.example` を `.env` にコピーし、SESSION_SECRETを長いランダム値に変更してください。

## 機能
18+確認、登録/ログイン、プロフィール、検索、いいね、相互マッチ、メッセージ、ブロック、通報、SQLite保存、Helmet、レート制限、スマホ対応。

## 本番前
HTTPS、正式な年齢確認・本人確認、利用規約/プライバシーポリシー等、管理者モデレーション、メール認証/パスワード再設定、永続DB/バックアップ、永続セッション、スパム/なりすまし対策、画像安全対策、日本の関連法令・届出等を確認してください。
